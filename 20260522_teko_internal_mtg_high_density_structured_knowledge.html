0. 全体構造

このMTGは単なる動画編集進捗確認ではなく、TEKOのYouTube/Instagram制作体制を「なおとさん個人の判断依存」から「編集者・ディレクター・撮影設計・企画思想が接続された運用体制」へ移行させるための設計会議だった。

1. 編集者採用の評価基準とトライアル設計

1.1 評価基準は「ディレクターなしで一定品質を出せるか」

青木さんとの前提では、分尺1000円程度の編集者であっても、ディレクターなしで一定品質を出せることが期待値になっていた。その基準で見ると、今回応募してきた男性候補3名は「ある程度マシ」ではあるが、単独で任せるには物足りない。ディレクターありなら成り立つが、分尺1000円の期待値から見ると弱い。

ここで重要なのは、今回候補を一律に低く見ていたわけではなく、なおとさん/パグさんは「今回の3名＋ポケモン系のかなかなさん」に対して、既存編集者より丁寧に作っている印象も持っていた点である。特にパグさんは、名前を挙げた候補について、ざっくり見た段階でも「ちゃんと丁寧に編集している」印象を示した。一方で、なおとさん側では、既存の大胡さん・坂野さんは比較的ざっくり・雑・粗いところがある、という対比が置かれていた。

つまり、この評価軸は単なる編集技術の有無ではなく、「細部まで気を配る制作姿勢」「素材/世界観/テロップ/効果音の統一感を見られるか」まで含む。今回の候補群は、その丁寧さの芽はあるが、TEKOの長尺をディレクターなしで任せ切れるかは別問題、という整理になる。

対象として名前が出た候補:

  • 山口拓真さん
  • 高橋大成さん
  • 前川智也さん

判断ニュアンス:

  • 技術的には候補に入る。
  • 既存の大胡さん・坂野さんより丁寧に見える候補もいるが、長尺を自走で任せる基準にはまだ届いていない。
  • 大胡さん・坂野さん側には、既存運用上「ざっくり・雑・粗い」印象があり、今回候補の丁寧さと比較対象になっていた。
  • ただし「ディレクターなしで成立する品質」には届いていない。
  • 長尺編集者として採用するなら、ディレクター/管理レイヤーとのセット運用が前提になる。

根拠: 00:00-02:27 / 05:11-07:49 / なおとさん補正

最も評価が高かったのは、かなかなさん（ポケモン系チャンネルを自分で伸ばし、大手系チャンネルにも関わっていると見られる女性編集者）。評価ポイントは、単なるカット/テロップではなく、世界観に合わせたBGM、イラスト挿入、テロップの統一感、細部の作り込みだった。

評価された要素:

  • BGM選定が世界観に合っている。
  • イラスト挿入が細かい。
  • テロップや見出しのトンマナが統一されている。
  • ポケモン文脈に合わせた細部の演出ができている。
  • 自分のチャンネルを2万人規模まで伸ばした経験がある可能性。

懸念:

1.3 トライアルは「編集実作業」と「ディレクション視点」を同時に見る

有力候補4名には、3,000円程度の有償トライアルを投げる想定。内容は、単純な編集テストではなく、冒頭2分の編集と、既存の粗い編集素材に対する改善コメントをセットにする。

トライアル内容:

  • ハイライトを含む冒頭2分部分の編集。
  • 既存の粗い編集素材（大胡さんの上げてきたメタメタな素材）に対し、「自分ならどう直すか」「どこがダメか」をコメントさせる。
  • コメントは編集者目線だけでなく、ディレクター目線も見る。

この設計の意味:

  • 手を動かす編集スキルだけでなく、品質判断能力を測る。
  • ディレクターが入らないと崩れる人材か、自走して改善できる人材かを見分ける。
  • なおとさん/パグさんがトライアル結果を一緒に揉める状態にする。

根拠: 05:11-07:26

2. 編集者レイヤーとリソース管理

2.1 長尺のカット/テロップ担当は「ディレクター前提」で成立しつつある

クラウドワークス経由の3名は、品質としては坂野さんより少し下くらいの感触。ただし、カット/テロップであれば、ディレクターが入る前提で現在の長尺クオリティ程度には到達できる見込みがある。

運用方針:

  • クラウドワークス経由の3名がOKなら、カット/テロップ実務を任せる。
  • すぐにカット/テロップだけを切り出せる既存人材はまだ薄い。
  • 仕上げが得意な女性編集者は、単純なカット/テロップより仕上げ側に回す方がよさそう。

根拠: 07:26-15:54

2.2 リモラボ女性候補は「動画編集できる事務」的な育成枠

リモラボから紹介された候補、という意味ではない。本人プロフィールにリモラボ受講歴があり、それによってリモラボ文脈の候補だと把握できた女性候補である。候補者としては初心者寄りで、ポートフォリオも弱い。ただし、だからこそ安いうちに抑え、小回りの利く編集/事務的役割として育てる余地がある。

期待役割:

  • カット/テロップのトライアル。
  • 低単価での小回り作業。
  • 動画編集もできる事務的ポジション。
  • 将来的に編集周辺の細かい作業を幅広く任せる。

採用判断の背景:

  • リモラボから紹介された候補ではなく、応募者本人がプロフィールにリモラボ受講歴を書いていたことで把握した。
  • リモラボ文脈だと「飛びづらい/やんちゃしにくい」と見た理由は、青木さんがリモラボ代表と旧知で、リモラボ内で講義をしたりCMO的な立場で影響力を持っているため。
  • そのため、青木さんの顔がある仕事で極端に雑な動きや離脱はしにくく、青木さんが絡んでいるうちの仕事として頑張る可能性がある、という見立て。
  • 仕事があれば何でも受けたい温度感の候補が多い。
  • 人に合った仕事があれば振れるよう、候補を押さえておく意味がある。

根拠: 08:10-10:39 / なおとさん補正

必要な管理項目:

連絡チャネルX DM / Chatwork大部屋 / 個別Chatwork
次アクショントライアル依頼 / 初稿確認 / ディレクターへ渡す / 保留

担当:

  • 作成担当はなおとさん。

3. ディレクター投入設計

3.1 属人チャンネルのフォーマット見積もりが起点

ディレクターはいつでも入れる状態だが、現状は属人チャンネル（プロパー八重洲ch/八重洲さんの動画）のフォーマット見積もり待ち。見積もりは翌日程度に来る想定だった。

3.2 属人チャンネル1本目は、まずカット/テロップまで進めてからパス

属人チャンネル1本目は、カット/テロップまで先に進め、見積もりやフォーマット方針が届き次第、ディレクター側へ渡す流れ。現時点でいきなり全部をディレクターへ渡すのではなく、制作工程の前段を進めておく判断だった。

実務上の流れ: 1. 大胡さん側でカット/テロップまで先行。 2. フォーマット見積もりを待つ。 3. 見積もり到着後、フォーマット作成/編集実制作の進め方を確認。 4. どちらかの形でディレクターへパス。

  • 初稿が上がっていて、ディレクターへ渡せる素材があるか。

  • 案件ごとの色のキャッチアップ。

なぜ重要か:

  • なおとさんが毎回クリエイティブ面の細かいフィードバックを入れる負荷が重い。
  • 既存編集者は本数をこなしていても、まだダサい素材・背景・クリエイティブを出すことがある。
  • ディレクターがこの層を吸収できれば、なおとさんはYouTube/Instagramマーケティングに集中できる。

4. ショート/リール制作体制の課題

長尺動画は、編集者配置とマネジメントがはまれば回りそうな感触が出てきている。一方で、ショート/リールは杉山さんワンオペに近い状態で、できる時にまとめて進める運用では限界がある。

ロング側の現状:

  • カット/テロップ担当候補が増えてきた。
  • ディレクターを入れれば品質を担保できる見込みがある。
  • 素材管理・データ管理もAIパイプライン化で安定してきた。

ショート/リール側の課題:

  • 杉山さん一人に寄りすぎている。
  • 感覚品質が求められ、単純な編集作業だけでは足りない。
  • 素材選定・背景・撮影品質で成果が大きく変わる。
  • なおとさんが都度クリエイティブ面を見続けると、本業に集中できない。
